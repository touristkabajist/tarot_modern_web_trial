# 设计方向：塔罗牌阵 · 现代扑克牌

## 候选方向

### 1. 午夜牌桌俱乐部（概率 0.07）
深靛夜色、墨绿绒布与香槟金标线，像一张克制而精致的现代扑克牌桌。

### 2. 霓虹牌库（概率 0.05）
黑色界面搭配电光蓝与玫红，强调快速抽牌的数字化氛围。

### 3. 晨雾纸牌工作室（概率 0.06）
暖白纸张、雾灰与酒红，像设计师桌面上的现代印刷扑克牌。

## 选定方向：午夜牌桌俱乐部

### 设计运动与核心原则
以**新式牌桌体验**取代神秘学装饰。视觉语气要沉静、精致、具有仪式感，但不使用传统塔罗的复杂符号。信息层级以「选择牌阵 → 开始抽牌 → 阅读牌意」为主线，始终让下一步行动清楚可见。

### 色彩理念
- 背景：深海军蓝 `#0B1426` 与墨绿 `#0E2A2B` 的柔和径向过渡。
- 品牌强调：香槟金 `#E6C77A`，用于分隔线、标志与焦点。
- 扑克红：`#C9434E`；扑克黑：`#182033`。
- 卡面：暖象牙白 `#FFFDF7`，确保牌面与文字清晰。

### 布局范式
顶部为小型品牌标识和状态徽章；主体采用居中的双栏结构：左侧是玩法说明和牌阵选择，右侧是绒布牌桌与结果。手机端折叠为单栏，牌阵选择保持在结果之前。

### 标志性元素
细金色双线、圆角玻璃面板、带细边框的深色绒布抽牌区、标准扑克牌角标与简洁花色。三张牌阵使用一条微妙的金色基线将“过去 / 当下 / 指引”串联。

### 交互与动画
选择牌阵时使用柔和边框过渡；抽牌时先短暂停留于背面，再翻转成牌面，牌面按从左到右的节奏显现。动效快速、可关闭（尊重 reduced motion），不妨碍读取。

### 字体系统
正文使用系统无衬线字体栈，强调可靠可读；品牌标题与大号牌名使用 Georgia 风格的高对比衬线字，营造纸牌印刷质感。中文回退使用 Noto Sans SC / 微软雅黑。

### 品牌本质与语气
品牌名为「一手牌局」。声音安静、笃定、略带启发性：不是预言，而是为当下提供一个思考角度。

### 标志与签名色
标志为香槟金的简化四花色罗盘：中心留白，四角以黑桃、红心、梅花、方块的几何轮廓暗示“牌阵”。签名色为香槟金 `#E6C77A`。

### 资产计划
- `public/logo.svg`：扁平化、全不透明、正方形香槟金四花色罗盘标志，供页面品牌区与应用图标使用。
- `public/favicon.svg`：同一标志的简化版本，供浏览器标签页使用。
- 卡牌不使用位图：以 CSS 和 Unicode 花色实现，确保扑克牌文字及符号清晰、可访问且可响应式缩放。
