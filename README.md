牌阵选择：
  支持切换「单张牌」、「三张牌」、二选一决策阵（5 张）、十字圣杯阵（10 张） ，当前选中的牌阵会有明确的高亮与标记。
  
现代扑克牌卡组：
  使用完整的 52 张黑桃、红心、梅花、方块标准扑克牌，点数涵盖 A 至 K，并在单次抽牌中严格随机且不重复。
  
牌阵展示与语境：
  点击「开始抽牌」后会有洗牌与揭牌动效。单张牌阵展示单张卡牌与解读；三张牌阵展示三张牌，并附带「过去 / 当下 / 指引」的位置语境与牌意提示。
  
重复体验：
  抽牌完成后可直接「再抽一次」，也支持「重新开始」或在不同牌阵间切换后重新抽取。
  
特点：
  使用现代扑克，不涉及复杂粽教叙事。
